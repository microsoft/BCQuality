# Support users onboarded via Mode C

Append-only registry of every Mode C (support-profile) onboarding — see
`curabis-standard.agent.md`'s MODE C section, Step 2.4. Never delete or edit
a row after the fact; if a user's access is later revoked or their profile
changes (e.g. promoted to full developer access), add a new row noting the
change rather than removing the original entry. This is what Rømer's
inspection round station 15 reads to periodically re-verify that every
support user still has no `Curabis/QualityHub` access and no Write+ role
anywhere — a registry with silently edited history defeats that check the
same way an edited `[CURABIS-STATE]` comment would.
